| 名词 | 释义 |
|---|---|
| 网货主体 | 现网客户企业（系统主数据） |
| 货主企业 | 「客户中心 → 网货货主」页面维护的主数据（货主ID 系统生成、支持页面导入）；锁站规则的选择器取自该主数据 |
| 客户商品管理推送 | 客户商品管理按网货主体维度展示的油站推送数据，锁站不生效时的兜底数据源 |
| 原企业价 | 「网点商品管理」维护的「油站 × 油品」价格（即调价前的企业价，本模块的价格基准） |
| 价格调整金额 | 在原企业价基础上调整的金额，单位元；正数=减价、负数=涨价、0=可见但不调价 |
| 锁后价 | 原企业价 − 价格调整金额（正减负加），不得小于 0 |
