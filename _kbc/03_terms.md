| 名词 | 释义 |
|---|---|
| 网货主体 | 现网客户企业（系统主数据） |
| 货主企业 | 「客户中心 → 网货货主」页面维护的主数据（货主ID 系统生成、支持页面导入）；锁站规则的选择器取自该主数据 |
| 客户商品管理推送 | 客户商品管理按网货主体维度展示的油站推送数据，锁站不生效时的兜底数据源 |
| 原企业价 | 「网点商品管理」维护的「油站 × 油品」价格（即调价前的企业价，本模块的价格基准） |
| 价格调整金额 | 在原企业价基础上调整的金额，单位元；正数=涨价、负数=降价、0=可见但不调价 |
| 锁后价 | 原企业价 + 价格调整金额（正加负减），不得小于 0 |
| 万联价 | 现网司机端在企业价基础上叠加展示的优惠价格（优惠后价格）；命中锁站锁价模式规则时不展示、不生效（锁站模式按现网已有价格规则照常展示） |
| 失效油站 | 规则明细内引用、但在「网点管理」已下线的油站；修改保存时拦截提示（可移除后保存），选油站弹层中置灰不可勾选（新建保存与启用不校验） |
