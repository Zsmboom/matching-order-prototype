1. 标题：「锁站规则详情」；页脚「导出 / 关闭 / 修改」。
2. 页头：规则编号（等宽字体）＋规则名称＋状态标签＋模式标签＋「N 行明细」标签；4 项指标：适用网货主体（N 个）／适用货主企业（N 个，未选择显示「全部」）／可见油站（M 个，按明细行油站去重）／有调整行（N 行，价格调整金额 ≠ 0 的行数）。
3. 基本信息：规则编号／规则状态／模式／创建（时间＋人）／最近修改（时间＋人）／备注（空显示「—」）；时间精确到分。
4. 适用网货主体：全量表，列【网货主体名称、网货主体ID】。
5. 适用货主企业：未选择显示「未指定货主企业，适用于上述网货主体下的全部货主企业」；≤ 20 个直接铺「名称＋ID」表（引导语「共 N 个货主企业」）；> 20 个启用「名称/ID 搜索（包含匹配）＋分页（20/50/100，默认 20）」，只渲染当前页，检索与翻页只重绘清单区、输入框不失焦，表尾常驻「当前筛选 X / 共 N 个货主企业」。数字例子：500 个货主 → 默认首页 20 行，搜索「天津」后表尾显示「当前筛选 X / 共 500 个」。
6. 油站与油品明细：全量逐行表（油站编码／油站·油站公司／油品／原企业价／成本价／价格调整金额／锁后价），不做分页与检索；价格调整金额列锁站模式显示「—」、锁站锁价模式正数显示「-金额」（减价）、负数显示「+金额」（涨价）、0 显示「0.00」；锁后价低于成本价标红。
7. 导出：页脚「导出」导出本规则全量名单（不受抽屉内搜索与翻页影响，不限规则状态）；导出为 1 个 Excel 文件、3 个 sheet，文件名「规则编号_规则名称.xlsx」（如 `AS2026100001_万联上海 · 沈阳天津锁站锁价.xlsx`）；导出后提示「已导出『<文件名>』（3 个 sheet：适用网货主体 N 行 · 适用货主企业 <X 个/全部> · 油站油品明细 M 行）」。sheet 结构：
   1. Sheet1 适用网货主体：一行＝一个主体，列【网货主体名称、网货主体ID】。
   2. Sheet2 适用货主企业：一行＝一个货主，列【货主企业名称、货主企业ID】；未选择货主企业（＝全部）时本 sheet 仅一行说明「未指定货主企业，适用于所选网货主体下全部货主企业」。
   3. Sheet3 油站油品明细：一行＝一条明细，列【油站编码、油站名称、油站公司、油品、原企业价、成本价、价格调整金额、锁后价】（锁站模式价格调整金额列＝「—」、锁后价＝原企业价）。
