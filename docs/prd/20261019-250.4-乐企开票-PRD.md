## 3 需求背景&目标

**背景**：《国家税务总局关于在成品油零售领域全面推广"交易即开票"有关事项的公告》（2026 年第 11 号）要求 2026-11-01 起全国成品油零售加油站全面推行"交易即开票"，既要保证笔笔开票及时性，又不能影响业务。平台能源订单当前依赖线下开票流程，无法满足按订单笔笔实时开票的要求。

**目标**：凡走易宝支付结算、直接与加油站结算的柴油能源订单（撮合易宝模式＋自营模式），支付成功后系统实时调用乐企自动开票，交易与开票解耦；订单列表呈现开票渠道、开票状态、失败原因与发票附件并支持手动开票、批量下载；所有退款在审核通过后先红冲原蓝票再执行退款，红冲失败拦截退款；网点公司管理提供「线上开票失败 n 笔自动下线」熔断配置；发票中心新增「订单发票管理」菜单沉淀撮合＋自营的乐企发票全量历史。

## 4 名词解释

| 名词 | 释义 |
|---|---|
| 乐企 | 税务部门面向企业的发票数字化开放平台，本需求使用其发票开具、开具结果查询、发票冲红、重试开具、发票文件重新发送五项接口能力 |
| 蓝票 / 红票 | 蓝票为正常开具的发票；红票为对原蓝票冲红后生成的负数发票，红票与原蓝票的对应关系通过发票序列与开票记录体现（订单发票管理列表保留「关联发票」列） |
| 进项票 / 票池 | 进项票=油站作为销方开具给平台的发票（自营业务购进侧）；票池管理=按货物名称、规格大类归集进项票数量库存的既有模块，销项开票消耗对应品类库存 |
| 红冲（冲红） | 对已开具蓝票发起冲销并生成红票的动作；本需求中红冲均由退款发起，无手动红冲入口 |
| 开票渠道 | 订单发票的开出来源，枚举：乐企、线下。线下=既有「客户申请＋油站上传」流程 |
| 交易即开票 | 支付成功即按订单维度实时开具发票，交易与开票解耦，开票失败不影响交易完成 |
| 自动下线（熔断） | 网点公司「线上开票失败 n 笔自动下线」配置：开票失败笔数达到阈值后系统自动停用该网点公司 |
| 应开票订单 | 满足应开票范围（柴油＋易宝支付＋直接与加油站结算）的能源订单 |

## 5.1 需求范围

- 端与用户：运营平台（PC），运营人员。
- 增量改造页面：订单管理、退款申请管理。
- 新增页面：自营订单管理、自营订单退款（订单中心）、网点公司管理（网点中心）、订单发票管理（发票中心新菜单）。
- 本期不含：天然气订单自动开票（不接乐企，按线下渠道口径处理与展示，口径不排斥天然气、后续政策要求时纳入）；三方对接站订单与非易宝支付订单（维持线下开票现状）；企业端、油站端页面；服务费订单开票；上线前已走易宝支付的历史订单（乐企不支持处理，维持原状）。

## 6.1 架构说明

运营平台各页面通过平台开票服务对接乐企开放平台：支付成功通知（易宝支付）触发乐企发票开具接口，通过开具结果查询接口轮询开具结果并回写订单开票状态与发票文件；退款审核通过与运营手动红冲由开票服务调用发票冲红接口；重试开具接口承担失败重试与手动开票，发票文件重新发送接口补拉发票文件。进项票侧：乐企获取的自营订单进项票自动同步入票池管理（按货物名称、规格大类归集数量库存），进项票红冲时删除票池对应记录；销项开票消耗对应品类的进项票数量库存。订单、退款、发票、网点配置数据均落平台库，订单发票管理按发票维度展示全量蓝/红票。企业开通/激活/授权沿用易宝现有能力，不做接口对接。

## 6.2 流程说明

1. 支付即开票：易宝支付成功→订单标记应线上开票（开票渠道=乐企）→实时调用发票开具接口，开具结果查询接口轮询：成功=开票成功并取得发票文件；失败=每分钟重试 1 次×3 次（重试开具接口），仍失败停留「开票失败」并记录失败原因。开票失败不影响交易正常进行。
2. 失败熔断：开票失败落定时，若该网点公司已开启「线上开票失败 n 笔自动下线」且当前开票失败笔数≥n，自动停用该网点公司（操作记录留存＋站内信/短信预警）；未配置或未达标转人工——运营在订单管理筛选「开票失败」手动开票，仍失败转技术排查。
3. 退款红冲前置（撮合与自营同规则）：退款审核通过时，若原蓝票为乐企渠道且开票成功未红冲，先调用发票冲红接口冲原蓝票——红冲成功→执行原有退款流程，退款成功=「红冲成功，退款成功」，资金侧失败=「红冲成功，退款失败」转人工；红冲失败→不执行退款、退款单终止为「退款失败」并展示原因，线下抵扣处理完成后重新发起退款申请，审核通过再次触发红冲。红冲进行中的订单拦截审核。线下渠道发票退款不拦截，维持现状。
4. 手动红冲与重开：运营对开票成功（或红冲失败重发）的乐企订单在「订单管理/自营订单管理」操作列发起手动红冲，调用发票冲红接口——成功→已红冲（原蓝票冲销），可再次手动开票重开蓝票，发票按蓝票→红票→新蓝票序列留痕；失败→停留「红冲失败」展示原因，可重新发起；红冲进行中拦截退款审核。
5. 票池库存联动：乐企获取到自营订单的进项票后按货物名称、规格大类记录到票池管理（数量入池）；销项票开票消耗对应品类的进项票数量库存；进项票红冲删除票池对应记录（不产生负数，等价于消耗库存），已开销项不追溯。

### 7.2.7 票池联动（进项票库存）
页面截图：无（现网既有页面 oilInvoicePoolInfo，本次仅新增联动逻辑，页面无需调整）
1. 进项票同步入池：自营订单中，乐企获取到进项票（油站作为销方开具给平台的发票）后，自动记录到票池管理的进项票中，按货物名称、规格大类归集，数量进入对应品类的可消耗库存。
2. 销项开票消耗额度：销项票开票消耗对应货物名称/规格大类的进项票数量库存；额度校验与品类匹配沿用票池既有逻辑，本次不调整。
3. 进项票红冲：乐企进项票红冲后，删除票池中对应的进项票记录——不产生负数记录，等价于消耗库存；已消耗的销项票不追溯，库存由后续进项票补充。

## 7.6 历史数据处理

上线前已走易宝支付的历史订单，乐企不支持处理，维持原有订单状态与线下开票口径不变；开票渠道按「线下」展示。如需批量更新历史订单的开票渠道/状态，由技术配合处理（MRD 数据需求），不在本需求产品范围。

## 8 测试重点

1. 应开票范围判定：柴油＋易宝支付＋直接与加油站结算三条件同时满足才自动开票；天然气、非易宝支付、三方对接站订单不开票且开票渠道=线下。
2. 乐企状态机流转：支付成功→开票中→开票成功/开票失败；失败自动重试每分钟 1 次×3 次后停留开票失败；退款审核通过或手动红冲触发红冲中→已红冲/红冲失败；列表展示最新 1 次开票结果（蓝＋红＋再开蓝的循环场景）。
3. 退款红冲前置三态：乐企蓝票未红冲→审核通过先红冲；红冲失败→不执行退款、退款单终止「退款失败」、订单置「红冲失败」；重新发起退款申请审核通过再次红冲；红冲中拦截审核；线下渠道不拦截。
4. 自动下线熔断：计数=该网点公司当前「开票状态=开票失败」的应开票订单数（历史全量、做过红冲不算）≥n 触发停用＋留痕＋预警；重新启用后计数从 0 累计；未开通易宝账户不可开启配置。
5. 发票数据一致性：每张蓝/红票在订单发票管理一行可见，红票关联原蓝票；订单开票状态与最新一次开票/红冲结果一致；手动开票（含已红冲重开蓝票）后状态与发票同步更新。
6. 票池库存联动：自营订单的乐企进项票入池后按货物名称、规格大类数量归集；销项开票消耗对应品类库存；进项票红冲删除票池记录、库存随之减少且不追溯已开销项。

## 7.2 功能说明（按页面）
### 7.2.1 订单管理
页面截图：img/orders.png
1. 开票渠道列：展示订单开票渠道，枚举【乐企、线下】；乐企显示高亮标签、线下显示普通标签；存量无渠道标识的订单按「线下」展示。
2. 开票状态列：按订单渠道分治展示——开票渠道=乐企展示 7 值状态【未开票、开票中、开票失败、开票成功、红冲中、红冲失败、已红冲】；开票渠道=线下展示 4 值状态【未开票、开票中、已开票、已撤销】；展示最新 1 次开票（蓝票＋红票）的结果。
3. 失败原因列：开票状态=开票失败或红冲失败时展示乐企返回原因（红色文字）；其余状态展示「—」。
4. 筛选项——开票渠道：下拉单选，默认「请选择」（全部）；选项【乐企、线下】；精确匹配订单开票渠道。
5. 筛选项——开票状态：下拉单选（按渠道分组展示），默认「请选择」（全部）；乐企分组选项【未开票、开票中、开票失败、开票成功、红冲中、红冲失败、已红冲】，线下分组选项【未开票、开票中、已开票、已撤销】；精确匹配订单当前开票状态；未选开票渠道时两组选项全部展示。
6. 手动开票：操作列入口，弹确认框（订单号/开票渠道/当前开票状态/失败原因/销方/购方/金额），确认后订单开票状态置「开票中」、失败原因清空、写入开票记录。
7. 手动红冲：操作列入口，弹确认框（订单号/开票渠道/当前开票状态/原蓝票号码/销方/购方/金额＋红冲原因必填 5–200 字）；确认后调用乐企发票冲红，订单开票状态置「红冲中」；成功→已红冲（原蓝票冲销），失败→红冲失败展示乐企原因，可再次发起；红冲中拦截退款审核。

3. 发票类型：枚举【蓝票、红票】；蓝票绿色标识、红票红色标识；金额红票展示负数。
4. 关联发票：红票展示其冲销的原蓝票发票号码；蓝票展示「—」。
5. 开票结果状态：蓝票=开票成功；红票=已红冲。
6. 触发方式：枚举【自动-支付成功、退款红冲、手动开票、手动红冲】。
7. 筛选项——订单流水号：文本输入，默认为空；MH / ZY 开头；精确匹配。
8. 筛选项——发票号码：文本输入，默认为空；数字票号；精确匹配。
9. 筛选项——业务线：下拉单选，默认「请选择」（全部）；选项【撮合、自营】；精确匹配。
10. 筛选项——发票类型：下拉单选，默认「请选择」（全部）；选项【蓝票、红票】；精确匹配。
11. 筛选项——开票时间：年月日时间范围组件，默认为空；与开票时间重叠即命中。
12. 附件操作：每行提供「查看」与「下载」；发票文件不限格式 url/pdf/ofd。
13. 导出：异步导出，按当前筛选结果导出，导出任务完成后在下载中心获取。
14. 列设置：支持配置列表列展示。

### 操作与状态
