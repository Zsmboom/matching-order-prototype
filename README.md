# 油气撮合业务原型

打开 `index.html` 即可查看交互原型；`live-alignment.js` 是运营中台现网页面对齐层，须与 `index.html` 放在同一目录。页面使用演示数据，不连接实际业务接口，也不会提交真实资金、退款或开票操作。

## 本次对齐页面

| 运营平台菜单 | 列表与详情 |
| --- | --- |
| 撮合订单 → 能源订单管理 | MH 能源订单；订单信息、发票信息、退款信息、操作日志；整单退款申请、撮合订单补单、批量开票预览 |
| 撮合订单 → 服务费订单管理 | 服务费流水、三方交易流水、关联能源订单；收付双方与发票信息；批量开票预览 |
| 撮合订单 → 退款申请管理 | MHRF 整单退款；退款申请信息、资金与业务影响；待审核申请的拒绝与通过确认 |
| 发票中心 → 能源发票管理 | KP 申请单、BAT 提交批次、能源与税率；申请单信息、订单明细、发票文件；上传、撤销与下载 |
| 发票中心 → 服务费发票管理 | FZK 申请单、支付方与金额；申请单信息、订单明细、发票文件；上传、撤销与下载 |
| 财务中心 → 服务费账户管理 → 服务费账户 | 可提现余额、累计收入、易宝流水、交易详情与导出 |
| 财务中心 → 油站公司账户 → 提现记录 | SW 提现单、账户与银行卡脱敏信息、处理进度与导出 |
| 客户中心 → 网货货主 | 网货货主主数据：筛选（货主ID / 货主名称）、下单概况、导入（同步校验）/ 导出（下载中心）、修改业务负责人、查看主体订单 |
| 商品中心 → 货主锁站锁价 | 按「网货主体 + 货主企业」锁定可见油站油品，并在企业价基础上按价格调整金额涨/减价 |

上述页面的筛选、列表、详情和操作弹窗按 2026-09-28 已打开的 OMS 实现整理；「客户中心 → 网货货主」按 2026-10-12 现网页面（路由 `oilWangHuoCustomerInfo`）补全。演示公司和交易记录经过替换；字段结构和页面操作保留。操作弹窗的确认按钮只显示原型提示。

## 货主锁站锁价（商品中心 · 独立菜单页）

完整方案见 [货主锁站锁价-方案说明.md](货主锁站锁价-方案说明.md)。要点：

- **界面风格**与其他运营页统一：页面随 `go()` 挂 `live-surface` 对齐层皮肤（菜单分组同为 OMS 结构），列表、抽屉、弹窗观感与已对齐运营页一致。
- **网货主体**＝现网客户企业，单独配置、搜索下拉获取；**货主企业**为主数据（由「客户中心 → 网货货主」页面维护，经导入进入），配置规则时从主数据**搜索多选**（按名称或 ID 模糊匹配，平铺全部、不随主体联动）。
- **适用范围拆成两个独立字段**：适用网货主体（多选）× 适用货主企业（多选），取笛卡尔积；适用货主企业为**必选项**（新建与编辑至少选择一家）——「不选＝全部货主企业」的场景由客户商品管理按网货主体的推送覆盖，不再通过规则表达。
- **模式只有两类**：锁站（价格沿用原企业价）／锁站锁价（逐行填写价格调整金额）。一条规则只能是其中一种。
- **价格口径**：按「油站 + 油品」逐行填价格调整金额（正数=减价、负数=涨价，涨价不设上限），锁后价 = 原企业价 − 价格调整金额；锁后价不得小于 0，低于成本价时保存前二次确认。
- **规则状态只有生效 / 停用**。
- **规则唯一性**：同一「网货主体 + 货主企业」至多一条生效规则，保存与启用时均校验，冲突拦截并提示冲突规则编号。
- **油站范围与可见性（2026-10-12 增补）**：规则可选油站为网点管理全部油站（价格在「网点商品管理」维护）；未随客户商品管理推送的油站，只要被「网货主体+货主企业」的生效规则配置，司机端同样展示并可加注；锁站不生效（无生效规则 / 停用 / 删除）时回落客户商品管理按网货主体的推送数据。
- **合同校验（2026-10-12 增补）**：添加油站时校验「油站×网货主体 有合同，或 油站×万油通主体 有签约合同」，无合同的油站拦截、不可添加（演示站 `ST0009` 锦州凌海物流站用于演示拦截）；订单生成时后端同样校验。
- **价格联动（2026-10-12 增补）**：价格调整金额同步驱动上游结算价与下游企业价，锁价生效期间生成的订单，上下游单价、金额、总金额同步变动且保持一致（测试重点）。
- **配置入口是抽屉**（与其他运营页一致的停靠形态），抽屉底部为「取消 / 保存」。
- **大数据量支持**：按油站 ≤300、货主企业 ≤500 设计。油站与油品明细、油站选择器两处支持「搜索 + 筛选 + 分页」（选择器与明细另带「只看已选 / 只看有调整的行」），翻页、筛选与勾选只重绘列表区（不重绘整个抽屉，搜索框不失焦）；货主企业搜索选择器支持名称 / ID 搜索 + 逐个勾选与移除。演示数据为 300 个油站 / 593 个油站油品行 / 520 个货主企业，用于验证分页与搜索。
- **适用范围列只保留数字**：列表「适用网货主体 / 适用货主企业 / 适用油站」三列只显示数字（右对齐）；完整名单在详情抽屉查看（网货主体名单表 / 货主企业清单，后者 ≤20 个直接铺表，超过 20 个启用「名称/ID 搜索 + 分页」，只渲染当前页）；列表筛选区保留网货主体下拉与货主企业名称模糊搜索。演示数据含 500 个货主企业的规则用于验证（`AS2026100006`，状态停用），并含「2 个/3 个网货主体」的多主体规则（`AS2026100004`、`AS2026100008`，状态停用）。
- **明细行数多了怎么展示**：加了对齐用的大数据量规则 `AS2026100007`（锁站锁价，覆盖全部 300 个油站共 593 行明细，状态停用），用于验证明细区的搜索、能源筛选、「只看有调整的行」与分页。
- **校验口径对齐《货主锁站锁价 · 产品需求文档》**：锁站锁价模式下价格调整金额**逐行必填**（新加入的明细行留空并标红，填 `0` 表示可见但不调价）；正数=减价、负数=涨价，最多两位小数，至少一行调整金额 ≠ 0；锁后价不得小于 0；锁后价低于成本价时保存前二次确认。规则名称 ≤50 字、备注为多行文本 ≤200 字。
- **详情导出**：详情抽屉底部「导出」导出本规则全量名单（不受抽屉内搜索与翻页影响），1 个 Excel 文件 3 个 sheet（适用网货主体 / 适用货主企业 / 油站油品明细），文件名「规则编号_规则名称.xlsx」；示例表格见页面底部「规则说明与设计口径 → 导出说明」。
- **关闭保护**：抽屉里有未保存改动时，点 ✕、点遮罩、按 Esc 或点「取消」都会先二次确认，确认后才放弃修改。
- **保存后的状态**：新建规则默认生效；**修改规则保持原有状态**，不会把停用规则因保存而静默启用。

页面地址 `#freightLock`。

## 网货货主（客户中心 · 独立菜单页）

按现网 OMS「客户中心 → 网货货主」（路由 `oilWangHuoCustomerInfo`）补全，并新增两个页头操作。要点：

- **列表按现网复刻**：筛选（货主ID、货主名称，均模糊匹配）＋ 9 列（序号、货主ID、货主名称、下单次数、累计实付、最近下单时间、业务负责人、创建时间、操作），分页 10/20/30/50/100/200/500 条每页。
- **导入（本次新增，同步）**：模板表头固定三列「货主ID / 货主名称 / 业务负责人（选填）」，货主ID 与货主名称必填；货主ID 与已有数据或本批内重复计入失败；合法行入库，失败行逐条提示原因，导入完成 toast 汇总成功/失败条数。
- **导出（本次新增，异步）**：按当前筛选结果提交下载中心任务。
- **修改业务负责人**：点击「业务负责人」单元格弹出修改弹窗，留空表示清除（空显示 `----`）；下单次数 / 累计实付 / 最近下单时间为系统统计，不可手工修改。
- **查看主体订单**：行操作弹窗，6 列（订单流水号、运单号、公司信息、司机信息、油站信息、支付状态），无订单显示「暂无数据」。
- **与锁站锁价的衔接**：本页主数据即货主锁站锁价「适用货主企业」选择器的数据源。

页面地址 `#oilWangHuoCustomerInfo`。

## 保留的新增方案

- 服务费订单继续显示“能源订单开票状态”“能源发票申请单号”，无明确关联时显示“—”；原“开票状态”明确为“服务费开票状态”。不在服务费订单增加“能源发票批次号”。
- 能源发票管理中的“提交批次号（BAT）”是现网存在的提交分组字段；“申请单号（KP）”是拆分后申请单编号，两者用途不同。
- 企业端日账单、月账单的“查看订单”使用统一右侧抽屉：顶部横幅锚定账单行汇总值（交易笔数、加油量、加油金额，月账单另含已开票金额），明细列为订单号/加油时间/司机姓名/司机手机号/车牌号/油站/商品/数量/加油金额/开票状态（司机与车辆按逐笔订单展示，账单列表汇总行不含），明细分页（默认 10 条/页，可调 10/20/50），合计行展示当前页笔数、数量、加油金额合计，翻页随页重算；明细卡头「导出」提交当前账单行全部订单明细的导出任务（字段与明细列一致、不加合计行、不受翻页与页大小影响，文件名「日/月账单_期间_能源类型.xlsx」，原型模拟异步任务不真实生成文件）；抽屉不展示客户承担服务费，也不单列与加油金额恒等的“消费合计”列。日账单页头「共 N 天」按自然日去重（同日柴油、天然气两行计 1 天）。
- 原型导航不展示“总分订单与核销”“额度扣减流水”“订单支付凭证管理”三个已移除菜单。
- 左侧顶部可切换**运营平台 / 油站端 / 企业端**三个站点，菜单只显示当前端的页面；运营平台沿用 OMS 菜单样式，只保留有页面的分组。页面地址带 `#页面ID`（如 `#cOrders`），可直接打开指定页面。
- 油站端：发票中心（发票管理、服务费发票列表）、财务管理（油站账户管理、油站资金流水）。
- 企业端：订单管理（订单列表、我的退款申请）、财务管理（我的余额与额度、日账单、月账单、账户资金流水）、发票管理（发票列表）。
