# 油气撮合业务原型

打开 `index.html` 即可查看交互原型；`live-alignment.js` 是运营中台现网页面对齐层，须与 `index.html` 放在同一目录。页面使用演示数据，不连接实际业务接口，也不会提交真实资金、退款或开票操作。

## 本次对齐页面

| 运营平台菜单 | 列表与详情 |
| --- | --- |
| 撮合订单 → 能源订单管理 | MH 能源订单；订单信息、发票信息、退款信息、操作日志；整单退款申请、撮合订单补单、批量开票预览 |
| 撮合订单 → 服务费订单管理 | 服务费流水、三方交易流水、关联能源订单；收付双方与发票信息；批量开票预览 |
| 撮合订单 → 退款申请管理 | MHRF 整单退款；退款申请信息、资金与业务影响；待审核申请的拒绝与通过确认 |
| 发票中心 → 能源发票管理 | KP 申请单、BAT 提交批次、能源与税率；申请单信息、订单明细、发票文件；上传、撤销与下载 |
| 发票中心 → 服务费发票管理 | FZK 申请单、支付方与金额；申请单信息、订单明细、发票文件；上传、撤销与下载 |
| 财务中心 → 服务费账户管理 → 服务费账户 | 可提现余额、累计收入、易宝流水、交易详情与导出 |
| 财务中心 → 油站公司账户 → 提现记录 | SW 提现单、账户与银行卡脱敏信息、处理进度与导出 |
| 商品中心 → 货主锁站锁价 | 按「网货主体 + 货主企业」锁定可见油站油品，并在企业价基础上减价 |

上述页面的筛选、列表、详情和操作弹窗按 2026-09-28 已打开的 OMS 实现整理。演示公司和交易记录经过替换；字段结构和页面操作保留。操作弹窗的确认按钮只显示原型提示。

## 货主锁站锁价（商品中心 · 独立菜单页）

完整方案见 [货主锁站锁价-方案说明.md](货主锁站锁价-方案说明.md)。要点：

- **界面风格**与其他运营页统一：页面随 `go()` 挂 `live-surface` 对齐层皮肤（菜单分组同为 OMS「商品中心」结构），列表、抽屉、弹窗观感与 7 个已对齐运营页一致。
- **网货主体**＝现网客户企业，单独配置、搜索下拉获取；**货主企业**由运营通过粘贴清单或 Excel 上传录入「名称 + 企业ID」，不预置组合。
- **适用范围拆成两个独立字段**：适用网货主体（多选）× 适用货主企业（多行），取笛卡尔积；货主企业留空表示该主体下全部货主企业。
- **模式只有两类**：锁站（价格沿用现网企业价）／锁站锁价（逐行减免价金额）。一条规则只能是其中一种。
- **价格口径**：按「油站 + 油品」逐行填减价金额，锁后价 = 现网企业价 − 减价金额；锁后价不得小于 0，低于成本价时保存前二次确认。
- **规则状态只有生效 / 停用**。
- **规则唯一性**：同一「网货主体 + 货主企业」至多一条生效规则，保存与启用时均校验，冲突拦截并提示冲突规则编号。
- **配置入口是抽屉**（与其他运营页一致的停靠形态），抽屉底部为「取消 / 保存」。
- **大数据量支持**：按油站 ≤300、货主企业 ≤500 设计。货主企业清单、油站与油品明细、油站选择器三处都支持「搜索 + 筛选 + 分页」（选择器与明细另带「只看已选 / 只看有减价的行」），翻页、筛选与勾选只重绘列表区（不重绘整个抽屉，搜索框不失焦）。演示数据为 300 个油站 / 593 个油站油品行 / 520 个货主企业，用于验证分页与搜索。
- **适用范围列只展示数量**：列表「适用网货主体」显示「N 个网货主体」、「适用货主企业」显示「N 个货主企业」或「全部货主企业」，不铺名称；完整名单在详情抽屉查看（网货主体名单表 / 货主企业清单，后者 ≤20 个直接铺表，超过 20 个启用「名称/ID 搜索 + 分页」，只渲染当前页）；列表筛选区保留网货主体下拉与货主企业名称模糊搜索。演示数据含 500 个货主企业的规则用于验证（`AS2026100006`，状态停用），并含「2 个/3 个网货主体」的多主体规则（`AS2026100004`、`AS2026100008`，状态停用）。
- **明细行数多了怎么展示**：加了对齐用的大数据量规则 `AS2026100007`（锁站锁价，覆盖全部 300 个油站共 593 行明细，状态停用），用于验证明细区的搜索、能源筛选、「只看有减价的行」与分页。
- **校验口径对齐《货主锁站锁价 · 产品需求文档》**：锁站锁价模式下减价金额**逐行必填**（新加入的明细行留空并标红，填 `0` 表示可见但不减价）；减价金额 ≥ 0、最多两位小数；锁后价不得小于 0；锁后价低于成本价时保存前二次确认。规则名称 ≤50 字、备注为多行文本 ≤200 字。
- **关闭保护**：抽屉里有未保存改动时，点 ✕、点遮罩、按 Esc 或点「取消」都会先二次确认，确认后才放弃修改。
- **保存后的状态**：新建规则默认生效；**修改规则保持原有状态**，不会把停用规则因保存而静默启用。

页面地址 `#freightLock`。

## 保留的新增方案

- 服务费订单继续显示“能源订单开票状态”“能源发票申请单号”，无明确关联时显示“—”；原“开票状态”明确为“服务费开票状态”。不在服务费订单增加“能源发票批次号”。
- 能源发票管理中的“提交批次号（BAT）”是现网存在的提交分组字段；“申请单号（KP）”是拆分后申请单编号，两者用途不同。
- 企业端日账单、月账单的“查看订单”仍使用统一右侧抽屉，明细只以当前账单行的演示数据为准；日/月账单与抽屉不展示客户承担服务费。
- 原型导航不展示“总分订单与核销”“额度扣减流水”“订单支付凭证管理”三个已移除菜单。
- 左侧顶部可切换**运营平台 / 油站端 / 企业端**三个站点，菜单只显示当前端的页面；运营平台沿用 OMS 菜单样式，只保留有页面的分组。页面地址带 `#页面ID`（如 `#cOrders`），可直接打开指定页面。
- 油站端：发票中心（发票管理、服务费发票列表）、财务管理（油站账户管理、油站资金流水）。
- 企业端：订单管理（订单列表、我的退款申请）、财务管理（我的余额与额度、日账单、月账单、账户资金流水）、发票管理（发票列表）。
