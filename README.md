# 油气撮合业务原型

打开 `index.html` 即可查看交互原型；`live-alignment.js` 是运营中台现网页面对齐层，须与 `index.html` 放在同一目录；`driver-h5.html`（司机端 H5）、`driver-h5-elec.html`（司机端-电 油气电 H5）与 `charging.html`（电业务运营后台）也要同目录，它们分别由 `#driverH5` 页、`#elecHome`…`#elecFailed`（司机端-电 18 页）与「充电业务」12 个页面以 iframe 承载。页面使用演示数据，不连接实际业务接口，也不会提交真实资金、退款或开票操作。

## 货主锁站锁价（商品中心 · 独立菜单页）

完整方案见 [货主锁站锁价-方案说明.md](货主锁站锁价-方案说明.md)。要点：

- **界面风格**与其他运营页统一：页面随 `go()` 挂 `live-surface` 对齐层皮肤（菜单分组同为 OMS 结构），列表、抽屉、弹窗观感与已对齐运营页一致。
- **网货主体**＝现网客户企业，单独配置、搜索下拉获取；**货主企业**为主数据（由「客户中心 → 网货货主」页面维护，经导入进入），配置规则时从主数据**搜索多选**（按名称或 ID 模糊匹配，平铺全部、不随主体联动）。
- **适用范围拆成两个独立字段**：适用网货主体（多选）× 适用货主企业（多选），取笛卡尔积；适用货主企业为**必选项**（新建与编辑至少选择一家）——「不选＝全部货主企业」的场景由客户商品管理按网货主体的推送覆盖，不再通过规则表达。
- **模式只有两类**：锁站（价格沿用原企业价）／锁站锁价（逐行填写价格调整金额）。一条规则只能是其中一种。
- **价格口径**：按「油站 + 油品」逐行填价格调整金额（正数=涨价、负数=降价，涨价不设上限），锁后价 = 原企业价 + 价格调整金额；锁后价不得小于 0，低于成本价时保存前二次确认。
- **规则状态只有生效 / 停用**。
- **规则唯一性**：同一「网货主体 + 货主企业」至多一条生效规则——**生效中的规则修改保存与启用时均校验**（冲突拦截并提示冲突规则编号）；**停用规则的修改保存不校验组合冲突**（2026-10-20 调整，可与任何规则同组合共存，启用时拦截）。
- **失效油站拦截（2026-10-20 增补）**：修改保存时校验明细内油站在「网点管理」是否下线（仅油站维度），下线则弹窗列出并拦截，可「移除下线油站并保存」；新建保存与启用不校验；选油站弹层中已下线油站置灰不可勾选（演示站 `ST0010` 沈阳新民物流站，挂在停用规则 `AS2026100005` 明细中用于演示）。
- **油站范围与可见性（2026-10-12 增补）**：规则可选油站为网点管理全部油站（价格在「网点商品管理」维护）；未随客户商品管理推送的油站，只要被「网货主体+货主企业」的生效规则配置，司机端同样展示并可加注；锁站不生效（无生效规则 / 停用 / 删除）时回落客户商品管理按网货主体的推送数据。
- **合同校验（2026-10-12 增补）**：添加油站时校验「油站×网货主体 有合同，或 油站×万油通主体 有签约合同」，无合同的油站拦截、不可添加（演示站 `ST0009` 锦州凌海物流站用于演示拦截）；订单生成时后端同样校验。
- **价格联动（2026-10-12 增补）**：价格调整金额同步驱动上游结算价与下游企业价，锁价生效期间生成的订单，上下游单价、金额、总金额同步变动且保持一致（测试重点）。
- **司机端价格展示（2026-10-20 修正）**：仅锁站锁价模式隐藏万联价——命中锁站锁价规则的组合，司机端只展示企业价（＝锁后价）、不展示万联价（企业价基础上的优惠价格，命中后不展示、不生效），订单按企业价计价结算；命中锁站模式规则的组合按现网已有价格规则展示（企业价＝原企业价、万联价照常）；未命中回落客户商品管理推送时企业价、万联价照常展示。
- **配置入口是抽屉**（与其他运营页一致的停靠形态），抽屉底部为「取消 / 保存」。
- **大数据量支持**：按油站 ≤300、货主企业 ≤500 设计。油站与油品明细、油站选择器两处支持「搜索 + 筛选 + 分页」（选择器与明细另带「只看已选 / 只看有调整的行」），翻页、筛选与勾选只重绘列表区（不重绘整个抽屉，搜索框不失焦）；货主企业搜索选择器支持名称 / ID 搜索 + 逐个勾选与移除。演示数据为 300 个油站 / 593 个油站油品行 / 520 个货主企业，用于验证分页与搜索。
- **适用范围列只保留数字**：列表「适用网货主体 / 适用货主企业 / 适用油站」三列只显示数字（右对齐）；完整名单在详情抽屉查看（网货主体名单表 / 货主企业清单，后者 ≤20 个直接铺表，超过 20 个启用「名称/ID 搜索 + 分页」，只渲染当前页）；列表筛选区保留网货主体下拉与货主企业名称模糊搜索。演示数据含 500 个货主企业的规则用于验证（`AS2026100006`，状态停用），并含「2 个/3 个网货主体」的多主体规则（`AS2026100004`、`AS2026100008`，状态停用）。
- **明细行数多了怎么展示**：加了对齐用的大数据量规则 `AS2026100007`（锁站锁价，覆盖全部 300 个油站共 593 行明细，状态停用），用于验证明细区的搜索、能源筛选、「只看有调整的行」与分页。
- **校验口径对齐《货主锁站锁价 · 产品需求文档》**：锁站锁价模式下价格调整金额**逐行必填**（新加入的明细行留空并标红，填 `0` 表示可见但不调价）；正数=涨价、负数=降价，最多两位小数，至少一行调整金额 ≠ 0；锁后价不得小于 0；锁后价低于成本价时保存前二次确认。规则名称 ≤50 字、备注为多行文本 ≤200 字。
- **详情导出**：详情抽屉底部「导出」导出本规则全量名单（不受抽屉内搜索与翻页影响），1 个 Excel 文件 3 个 sheet（适用网货主体 / 适用货主企业 / 油站油品明细），文件名「规则编号_规则名称.xlsx」；示例表格见页面底部「规则说明与设计口径 → 导出说明」。
- **关闭保护**：抽屉里有未保存改动时，点 ✕、点遮罩、按 Esc 或点「取消」都会先二次确认，确认后才放弃修改。
- **保存后的状态**：新建规则默认生效；**修改规则保持原有状态**，不会把停用规则因保存而静默启用。

页面地址 `#freightLock`。

## 网货货主（客户中心 · 独立菜单页）

按现网 OMS「客户中心 → 网货货主」（路由 `oilWangHuoCustomerInfo`）补全，并新增两个页头操作。要点：

- **列表按现网复刻**：筛选（货主ID、货主名称，均模糊匹配）＋ 9 列（序号、货主ID、货主名称、下单次数、累计实付、最近下单时间、业务负责人、创建时间、操作），分页 10/20/30/50/100/200/500 条每页。
- **导入（本次新增，同步）**：模板表头固定三列「货主ID / 货主名称 / 业务负责人（选填）」，货主ID 与货主名称必填；货主ID 与已有数据或本批内重复计入失败；合法行入库，失败行逐条提示原因，导入完成 toast 汇总成功/失败条数。
- **导出（本次新增，异步）**：按当前筛选结果提交下载中心任务。
- **修改业务负责人**：点击「业务负责人」单元格弹出修改弹窗，留空表示清除（空显示 `----`）；下单次数 / 累计实付 / 最近下单时间为系统统计，不可手工修改。
- **查看主体订单**：行操作弹窗，6 列（订单流水号、运单号、公司信息、司机信息、油站信息、支付状态），无订单显示「暂无数据」。
- **与锁站锁价的衔接**：本页主数据即货主锁站锁价「适用货主企业」选择器的数据源。

- 原型导航不展示“总分订单与核销”“额度扣减流水”“订单支付凭证管理”三个已移除菜单。
- 左侧顶部可切换**运营平台 / 油站端 / 企业端 / 司机端 / 司机端-电**五个站点，菜单只显示当前端的页面；运营平台沿用 OMS 菜单样式，只保留有页面的分组。端切换超过 4 个时自动换行（4 个端时不换行、按钮宽度不变）。页面地址带 `#页面ID`（如 `#cOrders`），可直接打开指定页面。
- 油站端：发票中心（发票管理、服务费发票列表）、财务管理（油站账户管理、油站资金流水）。
- 企业端：订单管理（订单列表、我的退款申请）、财务管理（我的余额与额度、日账单、月账单、账户资金流水）、发票管理（发票列表）。
- 司机端：网货 App 内嵌 H5「优惠加油」，独立文件 `driver-h5.html`，按 10 屏逐页入菜单（`#driverH5` 账户选择 起）；也可直接打开 `/driver-h5.html`（手机演示走这个地址）。

## 充电业务（运营平台 · 一级菜单，12 页）

要点：

- **形态**：电业务运营后台原型为独立文件 `charging.html`（自带客户中心 / 运营商中心 / 商品中心 / 订单中心 / 财务中心 5 组菜单）；运营平台左侧一级菜单「充电业务」平铺 12 页：客户管理、客户认证管理、客户合同管理、客户银行卡管理、运营商管理、运营商认证、运营商合同管理、运营商银行卡管理、充电站点管理、充电桩管理、充电枪管理、账户交易。
- **接入方式**：`index.html` 的 `VIEWS.chgXxx` 渲染 iframe `charging.html?embed=1&page=<key>`；该参数下 `charging.html` 隐藏自带左侧菜单与顶栏、内容区铺满运营平台外壳。不带参数直接打开 `charging.html` 仍是完整的「运营中台 · 电业务」（同一份文件双入口，零分叉）。
- **页签与深链**：切到充电业务时顶部页签只列本域 12 页（不与油气业务的页签混排）；`#chgCustomer`…`#chgTrade` 深链直达。
- **待建页面不进菜单**：网点电价管理、充电订单管理、电账户管理、对账单管理在交付文件里只有菜单占位、没有页面，本期不挂到运营平台；4PL 端的「充电订单管理」（网货司机云快充子订单）是另一条业务，不受影响。
- **数据源与演示数据**：充电站点/桩/枪标注「数据源：云快充 · 每日同步」，账户交易为「电账户流水 · 易宝结算」；演示数据与交付文件逐条一致（客户管理 11、客户认证 8、客户合同 8、客户银行卡 9、运营商 8、运营商认证 8、运营商合同 6、运营商银行卡 8、站点 8、桩 10、枪 20、账户交易 12），未做增补。
- **口径**：本次只搬运、不改业务逻辑；后续如需原生化（用运营平台组件重写页面），只替换对应 `VIEWS.chgXxx`，菜单与深链不变。

## 司机端 H5（网货 App 内嵌「优惠加油」）

要点：

- **形态**：独立文件 `driver-h5.html`（10 屏：账户选择 / 油站列表 / 地图 / 路线规划 / 路线地图 / 沿途列表 / 订单 / 油站详情 / 二维码支付 / 支付成功；6 个底部弹层 + OCR 提示框）。`index.html` 第 4 端「司机端」共 **17 个菜单项**（10 屏 + 7 个弹层），每页渲染手机壳 + 页头提示条 + iframe，不进 OMS 对齐层。
- **菜单与顺序（按使用流程 3 组）**：
  - 账户与选站：账户选择（`#driverH5`）、油站列表（`#oilHome`）
  - 地图与路线：地图找站（`#oilMap`）、路线规划（`#oilRoute`）、路线地图（`#oilRouteMap`）、沿途油站（`#oilRouteList`）
  - 订单与支付：油站详情（`#oilDetail`）、二维码支付（`#oilQr`）、**订单详情（支付成功）**（`#oilSuccess`）、订单列表（`#oilOrders`）
  - 弹层与提示（7 条，点开即弹出对应弹层）：确认油气额度账户（`#oilLayerAccountConfirm`）、排序和筛选（`#oilLayerFilter`）、选择省市（`#oilLayerProvince`）、选择商品/枪号（`#oilLayerProduct`）、计价说明（`#oilLayerSubsidy`）、支付确认（`#oilLayerConfirm`）、温馨提示 OCR 失败（`#oilLayerOcr`）
- **深链**：页面用 `driver-h5.html?screen=<屏 key>&auto=1`，弹层再叠加 `&sheet=<弹层 key>`；`auto=1` 时源文件启动段以「有补贴运单账户」直奔目标屏并打开指定弹层（原来必须先停在账户选择再手动点一次账户），不带该参数时行为完全不变——手机演示走 `/driver-h5.html` 仍是先选账户。
- **两个油气额度账户**：**有补贴运单账户**（按运单补贴率计价，展示**万联价**，账户徽标取账户内最高费率 8%，演示运单费率 6%/8%/5%）；**无补贴运单账户**（按**企业价**计价）。
- **计价链**：订单结算＝升数 × 企业价 → 司机实付＝结算 ×（1 − 补贴率） → 平台补贴＝结算 − 实付；**直降优惠**＝油机金额 − 结算；**合计优惠**＝油机金额 − 实付；**万联价＝企业价 ×（1 − 补贴率）**，仅用于支付前展示。计价说明弹层写明「先算结算、再算实付、最后结算−实付得补贴」。
- **组合支付**：不勾选运单＝按装货时间 FIFO 依次扣减同主体多张运单额度，补贴率取参与运单最高值统一计价；勾选单张运单＝只扣该运单、按自身费率；额度上限按「额度 ÷（1 − 补贴率）」反算最大可加注升数/金额。
- **加注录入**：详情页「本次加注」标题右侧可切「按升数 / 按金额」，站级默认值来自列表入口（部分站按金额、二维码站直接出示付款码）。
- **二维码支付**：出示付款码 → 油站扫码录入加注 → 司机确认；4 分 59 秒倒计时、过期提示、可刷新；二维码为内联 SVG，不依赖图片资源。
- **订单列表**：全部 / 待支付 / 支付成功 / 已退款四个分栏（可筛），演示 12 条（支付成功 8、待支付 2、已退款 2）；待支付显示「待扣」、已退款显示「已退」。
- **演示数据**：油站列表 12 家（距离排序，覆盖高速/非高速、8 个渠道枚举、0#/-10#/-20#/-35#/LNG/92#、按升/按金额/二维码三种入口）。
- **本期不与货主锁站锁价联动**：司机端价格只看账户口径（有补贴→万联价、无补贴→企业价），规则判定不在司机端做；页面 `sub` 与手机壳提示条已标明「演示数据，本期未与锁站规则联动」。联动留待第 2 期。

页面地址 `#driverH5`…`#oilOrders`（独立地址 `driver-h5.html`：不带参数先进账户选择，可叠加 `?screen=<key>&auto=1` 直达某屏；`?sheet=<弹层>` 仍可用）。

## 司机端-电 H5（网货 App 内嵌「充电服务」，18 页 + 17 弹层入菜单）

要点：

- **形态**：独立文件 `driver-h5-elec.html`（交付文件 + 12 行深链启动段），一个容器文件内装两份 H5——「油（加油加气）」与「电（充电服务）」，用 `?service=` 参数决定进入哪一份。`index.html` 新增第 5 端「司机端-电」（排在「司机端」之后），**电的 18 个页面各占一个菜单项**，每页渲染同一套手机壳 + iframe，不进 OMS 对齐层。
- **菜单与顺序（照源文件自带目录，5 组 18 页 + 弹层组 17 条，共 35 个菜单项）**：
  - 找站与账户：附近电站、选择额度分组、地图与沿途、路线规划、电站详情、进站指引
  - 扫码与启动：扫码识别、启动确认
  - 充电与结果：启动中、充电中、停止中、状态待核查
  - 账单与订单：已结束待结算、支付待处理、已支付与账单、我的充电订单、能源额度
  - 异常与恢复：启动失败
  - 弹层与提示（17 条，点开即弹出对应弹层）：联系场站与平台、了解运单电额度、筛选电站、电站排序、选择城市、全部时段价格、本单历史资费快照、本组电运单、本次额度使用规则、核对充电车辆、车牌拍照核验、场站位置核验、充电价格有变化、确认结束本次充电、订单处理轨迹、完整优惠账单、更多订单信息
- **页签**：顶部页签只列当前分组的页面（「找站与账户」6 页、「弹层与提示」17 条），与其他端现有行为一致。
- **深链**：页面用 `driver-h5-elec.html?service=charge&page=<源文件页面 key>`，弹层再叠加 `&sheet=<源文件弹层 key>`；文件末尾追加的启动段把 `?page=` 转成源文件本就支持的 `energy-command` 消息推给它的 iframe，页面到位后调源文件自己的 `showSheet(<key>)` 弹层（业务函数、数据、样式一行不改），最多重试 5 次、6 秒后停止，不与页内操作打架。本原型页面地址：`#elecHome`、`#elecAccounts`、`#elecMap`、`#elecRoute`、`#elecDetail`、`#elecGuide`、`#elecScan`、`#elecConfirm`、`#elecStarting`、`#elecCharging`、`#elecStopping`、`#elecUnknown`、`#elecEnded`、`#elecUnpaid`、`#elecPaid`、`#elecOrders`、`#elecWallet`、`#elecFailed`。
- **过渡态会自己往前走**：启动中、停止中、已结束待结算三页按源文件自带的演示时序会自动推进到下一状态（启动中→充电中、停止中→已结束、已结束→支付待处理）；「车牌拍照核验」弹层打开约 1 秒后源文件会自动通过核验并关闭。都是源文件行为，再点一次该菜单项可重播。
- **页内切换加油气**：充电首页右上「加油气 →」由源文件自己的 postMessage 切到新版油 H5（《万油通网货H5端》，含「选择补能类型」入口）；油那份顶部「去充电」切回电。
- **手机壳差异**：源文件 H5 自带状态栏（移动宽度下隐藏），因此这些页面的机身刘海隐藏（`.driver-phone.no-notch`），避免遮挡页头；「司机端」页的刘海与提示条保持原样。
- **演示数据**：与交付文件逐条一致，未做增补（电 18 页 / 14 个演示场景；油 10 屏）。
