# 撮合业务模式 · 订单与发票管理原型

PRD 配套的可交互原型，单文件、零依赖，双击 `index.html` 即可在浏览器打开。

在线预览：https://zsmboom.github.io/matching-order-prototype/

包含 21 个可访问页面，菜单按**三级结构**组织：平台端 → 业务模块 → 菜单。

**运营平台 · 订单中心**　能源订单 / 服务费订单 / 总分订单与核销 / 订单退款申请与审核 / 额度扣减流水

**运营平台 · 财务中心**　资金交易流水明细 / 订单支付凭证管理 / 服务费账户

**运营平台 · 发票中心**　能源发票管理 / 服务费发票管理

**企业端 · 订单管理**　订单列表 / 我的退款申请

**企业端 · 财务管理**　我的余额与额度 / 日账单 / 月账单 / 账户资金流水

**企业端 · 发票管理**　发票列表

**油站端 · 财务管理**　油站账户管理 / 油站资金流水

**油站端 · 发票中心**　发票管理 / 服务费发票列表

油站端的订单类页面（接单、核销、扫码确认）本次不在交付范围。

每页底部「规则说明与设计口径」可展开，是给研发和测试看的逻辑说明（前置条件、操作可用性、提交后的处理、流程图）。

## 近期口径变更

- 订单列表字段：客户企业 → **总公司**，归属分公司 → **分公司**，总订单金额 → **加油金额**，去掉**对账状态**列
- **服务费拆为独立菜单**「服务费明细」：记录支付方（油站 / 客户），并有独立的支付状态与开票状态。订单页的支付状态与开票状态从此**只针对油款**
- 客户端是否展示服务费，取决于该笔订单的**支付方**：油站承担不展示、客户承担必须展示
- 服务费明细补齐**详情页**（计算过程、支付方与收款方、支付进度、开票信息）
- **订单补录**精简：去掉补录类型、油卡类型、运单号、总订单号、补录人；枪价改称单价；油款金额改为可手工修改（与自动计算值的差异会提示并记入日志）
- 删除全部**接口请求与返回留痕**（请求/返回 JSON、报文快照、接口路径），业务字段全部保留
- **总分订单**子单行只记该运单的额度扣减（占用前可用 / 本次扣减 / 剩余可用），不再摊服务费
- **订单退款**改版：发起方只有油站和运营平台，取消两道审批，「审核」退化为一次确认操作；订单列表入口默认整单退款，计量差异等经核实场景可由异常流程生成差额退款；退款状态为 待审核 / 审核中 / 已退款；补全退款详情页
- **企业端 · 财务管理**以我的余额与额度、日账单、月账单、账户资金流水组成核对链路；充值和退款作为独立资金类型混排在账户资金流水中
- 企业日账单、月账单和账户资金流水统一服务费口径：只统计**客户承担且已记入企业账户**的服务费；油站承担部分不向企业端下发，也不计入消费合计
- **服务费账户**归属运营平台；油站端财务只保留油站账户管理和油站资金流水，正式接口按当前登录油站隔离数据
- 服务费账户不设置或展示单独的资金流水号，列表、筛选、详情、导出与对账均以**易宝流水号**为准
- 油站账户权限已收口：账户启停、D0 / D1 到账方式由运营平台控制；油站端只可查看本主体账户、发起提现并维护定期提现规则
- 菜单改为**三级结构**：一级平台端（运营平台 / 油站端 / 企业端）→ 二级业务模块（订单中心或订单管理 / 财务中心或财务管理 / 发票中心或发票管理）→ 三级菜单；权限边界即菜单树第一层
- 新增全站**二次确认弹窗**体系：动钱、改数据、不可逆的操作统一先弹确认，含后果说明、关键金额、核对信息与必填理由
- 订单页顶部统计只留**合计订单数量**与**合计金额**，且跟随筛选联动
- 订单详情重新分组为**交易详情 / 商品信息 / 客户信息 / 支付信息 / 发票信息**，支付与发票两段把油款和服务费并列展示
- 补录的**油机小票号与凭证影像改为非必填**，必填只剩补录原因；风控从卡入口改为事后可查
- **服务费明细 → 服务费订单**，新增申请开票（单笔 / 批量）与发票下载
- 能源发票与服务费发票申请状态统一为**待开票 / 已开票 / 已撤销**；申请提交成功即进入待开票，本期不实现部分开票
- 能源申请按**开票方 + 受票方 + 能源类型**拆单；服务费申请仅按**支付方**拆单，不按账期或能源类型拆分
- 能源可开票资格由订单主状态、支付状态联合判定，并暂以**分账处理完成**为前置条件；服务费资格只看订单状态与支付状态，不依赖账单确认
- 拆票仅按单张票额阈值执行，结果只在申请预览展示；详情不展示拆票信息，也不按行数拆票
- 三端能源及服务费申请单详情统一为**申请单信息 / 订单明细 / 发票文件**三个页签；订单明细只保留订单流水号、加油时间、商品数量、金额与查看入口
- 发票文件仅支持图片和 PDF；单张直接下载，批量下载与导出异步进入下载中心，单批最多 2 万条，完成后推送提醒
- 本期不实现红冲、自动开票、催办、开票预填单、退款逆向联动和油站超时默认确认服务费账单
- 数据按主体隔离：企业总公司可看所属全部子公司、子公司仅看自身；油站端按油站公司查看其下全部油站
- 所有详情抽屉统一为左侧纵向图标 Tab、右侧内容面板；窄屏改为顶部横向滚动

## 发布成网页

把整个目录推到仓库，然后在仓库设置里开启 Pages 服务，指向该分支根目录。

注意：直接访问 raw 文件地址（raw.githubusercontent.com 等）打不开页面，只会显示源码——raw 服务返回的是纯文本类型。必须走 Pages 服务。

`.nojekyll` 是给 GitHub Pages 用的，避免它拿 Jekyll 处理静态文件。
